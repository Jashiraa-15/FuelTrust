# FuelTrust — Frontend Client Application

The user interface for **FuelTrust: Smart Fuel Verification & Vehicle Efficiency Monitoring**.

## Technology Stack

- **React 19** with **TypeScript**
- **Vite** build tooling & HMR
- **Tailwind CSS** (White Glassmorphism UI design system)
- **Recharts** for metric visualization
- **Lucide React** iconography

## Development

```bash
# Install dependencies
npm install

# Launch Vite development server
npm run dev

# Build for production
npm run build
```
